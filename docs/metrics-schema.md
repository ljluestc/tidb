# Metrics Schema

This document describes the metrics available in TiDB.

## Schema Metrics

The following metrics provide information about database schemas:

| Metric Name | Description |
|-------------|-------------|
| `tidb_schema_database_count` | Number of databases in the TiDB server |
| `tidb_schema_table_count` | Number of tables in the TiDB server |
| `tidb_schema_version` | Current schema version of the TiDB server |
